# GitHub repo release steps

These are manual settings in the GitHub UI. They are not applied by a push.

## Social preview

Upload the 1280×640 preview image so link unfurls (Slack, X, iMessage, and
the repo Explore card) show the PilotLight card instead of a cropped README
screenshot.

1. Open the repository on GitHub.
2. Go to **Settings → General**.
3. Under **Social preview**, click **Edit** and upload:

   `docs/github/pilotlight-github-social-1280x640.png`

The file is 1280×640 PNG and already lives in this repository. GitHub does
not pick it up from the tree; it has to be uploaded in Settings.
